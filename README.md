# hass_openwrt_control

Интеграция Home Assistant с автономным OpenWrt VPN Controller для управления VPN и секциями Podkop.

Статус: проектирование. Реализация контроллера и интеграции пока отсутствует.

## Документация

- [Дополнение к ТЗ: анализ FUjr, сравнение SSH/ubus, RPC-контракт и безопасность](docs/transport-ubus-addendum.md)

## Архитектура

Home Assistant → HTTPS ubus JSON-RPC с проверкой сервера → локальный OpenWrt VPN Controller → UCI/Podkop.

Контроллер сохраняет автономность при недоступности Home Assistant. Требования включают отдельную RPC-учётную запись и минимальную ACL, защиту `inbound_vpn`, независимые политики секций Podkop, проверку реального выхода через VPN и транзакционный откат. SSH предусмотрен для установки и как явно включаемый резервный транспорт.

Первоначальное полное ТЗ пока не добавлено. Дополнение сохраняет остальные его требования и не заменяет исходный документ.
